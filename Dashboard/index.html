    API 接口一览
    
GET  /api/health                     # 核心健康检测与运行时信息
GET  /api/adapter/status             # 当前适配器内核运行状态
POST /api/sniff                      # 节点链接与跨内核配置嗅探
POST /api/chain/compile              # 跨内核多跳链式代理编译
POST /api/chain/landing              # 自定义落地参数校验与构造
POST /api/custom-options             # 获取自定义开关模式
POST /api/custom-options/resolve     # 开关参数校验与合并
POST /api/script/mihomo/compile      # Mihomo 完整脚本覆写编译
